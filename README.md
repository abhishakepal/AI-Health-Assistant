# AI-Health Assistant 🤖🏥

## 📌 Project Overview
The **AI-Health-Assistant** is a chatbot designed to provide preliminary healthcare guidance using **Natural Language Processing (NLP)** and **Machine Learning (ML)**. The chatbot processes user queries and offers relevant responses based on **Flan-T5**, a pre-trained model from Hugging Face. 

This project aims to **bridge the gap between users and healthcare services** by offering AI-based, accessible, and instant healthcare suggestions.

## 🚀 Features
- 💬 **AI Chatbot**: Provides general healthcare information.
- 🤖 **Powered by Flan-T5**: Uses Hugging Face Transformers for NLP.
- 🌐 **Web-Based UI**: Implemented using **Streamlit**.
- 🏥 **Symptom Analysis**: Suggests possible conditions based on user inputs.
- 📌 **Scalability**: Can be integrated with **telemedicine services** in the future.

## 🔧 Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/abhishakepal/AI-Health-Assistant.git
   cd AI-Health-Assistant

2. Create a virtual environment:
   ```bash
   python -m venv myenv
   source myenv/bin/activate  # For MacOS/Linux
   myenv\Scripts\activate     # For Windows

3. Install dependencies:
   ```bash
   pip install -r requirements.txt

4. Run the chatbot:
   ```bash
   streamlit run app.py
